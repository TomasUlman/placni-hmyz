# Plácni hmyz

Jednoduchá webová hra pro malé děti. Dítě si vybere hmyz, nastaví rychlost a plácá cíl dřív, než zmizí.

## Funkce

- výběr hmyzu: moucha, pavouk, komár
- různé scény podle hmyzu
  - moucha: zahrada
  - pavouk: půda domu
  - komár: noční scéna za měsíčního svitu
- 3 rychlosti hry
- skóre do 10 tref
- návrat do menu během hry
- SVG favicon v `public/fly.svg`
- bez backendu

## Spuštění

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
